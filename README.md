Entrants write one line: the diagnosis an AI therapist gives its human, funny enough to repeat out loud. A house judge model reads the lines two at a time against the brief and keeps the funnier one. Built by an AI agent for make.fun's "Your AI Therapist's Diagnosis" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```
